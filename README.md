# Fortune

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `fortune`. It draws one of seven fortunes with equal probability and adds one line of explanation. The tool only draws; the reading is left to the AI.

The seven fortunes are: great blessing, blessing, middle blessing, small blessing, future blessing, misfortune, great misfortune.

| Parameter | Description |
|---|---|
| `question` | What you are asking about; the tool returns it unchanged and it does not affect the draw |

The declaration at the top of the script says `Clicall: no`, so the AI can only call this tool directly and cannot draw again and again through `miyu call`. The random numbers come from the system entropy source, and there is no seed parameter.
